# СППР — фронтенд

React (Vite, TypeScript): альтернативи, критерії, редагування матриці оцінювання, перегляд рейтингу з діаграмою та поясненням.

## Запуск

1. Запустіть бекенд з кореня репозиторію: `npm run start:dev` (порт 3000).
2. Тут: `npm install` → `npm run dev` (порт 5173).

Проксі в `vite.config.ts` пересилає `/api` на `http://127.0.0.1:3000`.

## Збірка

`npm run build` — каталог `dist/`. Для звернення до API на іншому хості задайте `VITE_API_BASE` (див. `.env.example`).
